# NEXPOS: Pricing Proposal Structure (Tanzanian SMB Retail)

*Note: This is a framework for sales proposals, not a final invoice. All prices are in Tanzanian Shillings (TZS).*

## Standard Fees
- **Setup / Onboarding Fee:** One-time cost for server provisioning, initial data import, and tenant creation. (e.g., TZS 300,000 - 500,000)
- **Monthly Subscription (Hosting, Support, Maintenance):** Base fee for keeping the cloud system active and secure. (e.g., TZS 80,000 - 150,000 / month)

## Optional / Expansion Fees
- **Multi-Branch Setup Fee:** Onboarding fee per additional physical location. (e.g., TZS 150,000 / branch)
- **Module Expansion Fees:** Adding modules like Expense Tracking or Multi-Branch Transfers once released. (e.g., TZS 20,000 - 50,000 / month per module)
- **On-Site Training Fee:** Dedicated in-person staff training sessions. (e.g., TZS 150,000 / day)
- **Custom Reports Fee:** Development of bespoke analytics dashboards specific to the client's business model. (e.g., TZS 400,000+ one-time)

---

## Suggested Package Tiers

### 1. Starter Demo Pilot (1 Branch, Core POS only)
*Designed to lower the barrier to entry and prove value.*
- **Setup:** TZS 150,000 (Discounted)
- **Monthly:** TZS 50,000
- **Includes:** Core POS, Inventory, 3 User Accounts (Owner, Manager, Cashier).
- **Goal:** Convert to Retail Core after 30 days of proven success.

### 2. Retail Core (1 Branch, Full Core Features)
*The standard single-location setup.*
- **Setup:** TZS 350,000
- **Monthly:** TZS 80,000
- **Includes:** POS, Inventory, Standard Reporting, Unlimited Users for one branch.

### 3. Retail Operations (2-3 Branches)
*For growing businesses that need cross-branch visibility.*
- **Setup:** TZS 600,000
- **Monthly:** TZS 150,000
- **Includes:** Everything in Core, plus Multi-Branch management and upcoming Transfer modules.

### 4. Custom Enterprise (4+ Branches or Custom Needs)
*Bespoke rollout requiring significant data migration and custom engineering.*
- **Setup:** TZS 1,500,000+
- **Monthly:** Custom pricing based on server load (Starting at TZS 300,000)
- **Includes:** VIP Support, On-site training included, Custom module priority.
