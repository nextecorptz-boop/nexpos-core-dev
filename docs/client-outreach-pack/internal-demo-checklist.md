# NEXPOS: Internal Demo Checklist

**Run this checklist 30 minutes before every client demonstration.**

### 1. Environment & Connectivity
- [ ] Verify `https://nexpos-v1-demo.vercel.app` is loading quickly.
- [ ] Connect your primary device to a stable WiFi network.
- [ ] Have a 4G mobile hotspot turned ON and ready as a backup.
- [ ] Ensure browser cache is cleared or use an Incognito/Private window to prevent old session conflicts.

### 2. Login Verification
- [ ] Test `owner@nexpos.dev` (`password123`). Confirm redirect to `/app/dashboard`. Logout.
- [ ] Test `manager@nexpos.dev` (`password123`). Confirm redirect to `/app/dashboard`. Logout.
- [ ] Test `cashier@nexpos.dev` (`password123`). Confirm redirect to `/app/pos`. Keep this tab open if doing a POS-first demo.

### 3. Data & State Check
- [ ] Go to Inventory as Manager: Ensure there is enough stock for "Air Force 1 White" (Size 42) to perform a live checkout.
- [ ] If stock is zero, manually adjust it or pick a different item for the live POS demonstration.
- [ ] Verify the Dashboard charts are displaying data cleanly.

### 4. Hardware Preparation
- [ ] Ensure the tablet/laptop screen is clean.
- [ ] Turn off distracting desktop notifications (Do Not Disturb mode).
- [ ] Maximize the browser window (F11) to make it look like a native application.

### 5. Sales Materials Ready
- [ ] Have the `sales-one-pager.pdf` printed or ready to send via WhatsApp.
- [ ] Have the `pricing-proposal-structure.pdf` ready in case the client asks for immediate numbers.
- [ ] Have the `screenshot-capture-checklist` shots saved in a gallery for quick reference if the internet fails.
